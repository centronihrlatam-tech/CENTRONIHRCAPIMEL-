# Changelog

All notable **public** changes to this repository will be documented here.

This changelog begins with the first public portfolio release. It does not attempt to reconstruct the complete private development history that existed before publication on GitHub.

## Unreleased

- Added MIT License for the sanitized public source-code release.
- Updated README and provenance documentation to reflect the repository licensing terms.

## 1.0.0 — Initial public portfolio release

Included capabilities:

- Telegram-based activity registration.
- Free-text natural-language processing.
- Guided registration through dynamic buttons.
- Hybrid button + free-text workflows.
- Dynamic extraction of valid planner labels.
- Multiple user roles and planner routing.
- Google Sheets planner integration.
- Google Drive evidence upload and automatic evidence-link registration.
- Retrospective activity registration by date.
- Centralized usage and adoption analytics with configurable private aliases.
- Built-in `/tutorial` onboarding and configurable support contact.
- Script Properties configuration.
- Webhook-secret validation and private-chat authorization.
- Spreadsheet formula-injection protection.
- Public documentation in English and Spanish.
- Separation of production configuration and data from source code.
